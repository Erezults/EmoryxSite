# T048 — Tour screenshot parity between languages · הושלם ✅

## מצב סופי
זוגיות מלאה: **9/9 אריחים בשתי השפות**, כל אחד עם כיתוב בשפה הנכונה. הבילד (`npm run build`) עובר, והעמוד הסטטי מפנה לכל 9 האריחים בכל שפה מהתיקייה המקומית שלה (ללא fallback חוצה-שפות).

## מה בוצע (שני עובדים במקביל — העבודות משלימות)
1. **מנגנון קוד** (קומיט `2e6aab3`, עובד מקביל): `lib/screenshots.ts` מחשב ב-build את איחוד האריחים מהדיסק; כל שפה מעדיפה קובץ מקומי עם fallback לשפה השנייה. `Tour.tsx` מקבל את הרשימה כ-prop.
2. **נכסים מקומיים אמיתיים** (קומיטים `44ccffe`, `a252988`, `c8f5c28`, העבודה שלי): נוצרו 5 האריחים החסרים —
   - `he/01-vault-home.webp` — "מרחב פרטי לחיים שלך"
   - `he/06-media-viewer.webp` — "לחיות מחדש כל רגע"
   - `he/08-share.webp` — "שיתוף ישירות אל הכספת"
   - `en/05-import.webp` — "Import. Secure. Relax."
   - `en/07-settings.webp` — "Backed up. Encrypted. Yours."

## איך נוצרו (צינור ניתן לשחזור — `.erza/tour-gen/`)
- `blank.py` — שחזור הרקע המשותף (זהה ביט-מדויק בכל האריחים) במודל תלת-עוגני + סינון ערכים חריגים, ומחיקת אזור הכיתוב מאריח השפה הנגדית.
- `gen.py` — רינדור כיתוב חדש ב-HTML/CSS (Space Grotesk / Rubik / Geist / Assistant מ-Google Fonts) דרך Chrome headless, ואז `cwebp -q 82`. הטיפוגרפיה כוילה מול אריחי `02-lock-pin` הקיימים עד התאמה של ±1-2px בגובה/רוחב/מיקום/צבע (#FFC72E צהוב, #C2C0F1 תת-כותרת).
- הרצה מחדש: `python3 .erza/tour-gen/blank.py && python3 .erza/tour-gen/gen.py build` (דורש numpy, PIL, ImageMagick, cwebp, Chrome).

## ⚠️ מגבלה ידועה — לתשומת לב ארז
בתוך מסגרת הטלפון, צילום המסך של ה-UI עדיין בשפת המקור (באריחים העבריים החדשים ה-UI באנגלית, ובשני האנגליים החדשים ה-UI בעברית) — צילומי מסך מקוריים של האפליקציה בשפת היעד לא קיימים ברפו הזה, ולפי בידוד המשימה לא נגעתי בפרויקטים אחרים. כשיהיו צילומים אמיתיים (מהסימולטור/מכשיר בשפה המתאימה), אפשר או להחליף את קובץ ה-webp ישירות, או לשלב אותם דרך הצינור ב-`.erza/tour-gen/`. שום שינוי קוד לא יידרש.
