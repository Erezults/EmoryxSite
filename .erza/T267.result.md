## What was done (4 fixes, all committed to `main`, not pushed)

1. **Fixed real contrast failure** — `--color-text-dim` (`#5C5C6A` on `#08080B`)
   measured ~3.05:1, below the 4.5:1 AA minimum for normal text. Changed to
   `#78788A` (~4.6:1). commit `e3d6b97`.
2. **Alt-text / keyboard-nav audit** — images already had proper `alt`, all
   interactive components (FAQ accordion, language toggle) already used real
   `<button>`/`aria-expanded`/`aria-pressed` and were keyboard-operable, focus-visible
   ring already existed. Added the one real gap found: a localized "skip to content"
   link + `id="main-content"` landmark (WCAG 2.4.1 Bypass Blocks) — the site had no
   way to skip the repeated header nav. commit `e3d6b97`.
3. **Accessibility statement page** (`/accessibility`, EN+HE, linked from header nav
   and footer) — conformance level, list of implemented measures, known limitations,
   and a named accessibility coordinator (Erez Cohen, email — per the checklist,
   name + phone *or* email satisfies the "human contact" requirement) with a 14
   business-day response commitment. commit `a519794`.
   - Side fix bundled into the same commit: adding a 5th header nav link exposed a
     **pre-existing** mobile nav overflow bug (language toggle already fell off-screen
     at 390px width even before my change, verified via screenshot). Made the nav
     horizontally scrollable + tightened mobile spacing so every link (including the
     new legally-required one) stays keyboard-reachable and swipeable on small
     screens, without a full redesign.
4. **On-site accessibility widget** — floating button (bottom-right, chosen to avoid
   colliding with the Next.js dev-mode overlay which always sits bottom-left) offering
   text-size cycling (default/large/x-large), a high-contrast palette toggle, and a
   "stop animations" toggle (on top of the existing `prefers-reduced-motion` support),
   persisted in `localStorage`. Verified via Playwright: toggles apply the correct
   `data-a11y-*` attributes, font-size actually changes computed style, and state
   survives a full page reload. commit `a5248d9`.
